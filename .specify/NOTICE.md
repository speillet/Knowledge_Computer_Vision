# Provenance des fichiers Spec Kit

Les skills `.agents/skills/speckit-*/SKILL.md`, les scripts, modèles et fichiers
de workflow générés dans `.specify/` proviennent de
[GitHub Spec Kit 1.2.1](https://github.com/github/spec-kit/tree/v1.2.1),
révision `9dca9bf42a031765ee5e5f2371137f2f26967e11`.

Ils ont été installés avec l'intégration Codex et les scripts Bash. Les manifestes
conservent les empreintes des fichiers fournis par cette version.
La constitution du projet est encore le modèle généré, sans ratification.

La notice MIT de GitHub est conservée dans [LICENSE](LICENSE). Elle s'applique
aux éléments provenant de Spec Kit, y compris les skills du dossier `.agents/`.
La licence du contenu original de ce dépôt se trouve à sa racine.
