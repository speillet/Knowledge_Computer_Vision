# Knowledge Computer Vision

Construire un vault Obsidian de connaissances et de flashcards pour progresser
vers un niveau de Computer Vision Engineer senior.

Le public cible est un ingénieur expérimenté en ML/DL. La base doit approfondir
les techniques de vision classiques et modernes avec des explications en français,
des termes techniques anglais, des équations expliquées et du code utile.

## Outils de travail

- [Conventions de contribution](CONTRIBUTING.md) : branches, commits et PR.
- [Instructions pour les agents](AGENTS.md) : objectifs et règles du dépôt.
- [Audit des outils](docs/tooling-audit.md) : installation locale, sources et limites.
- [Provenance de Spec Kit](.specify/NOTICE.md) : version et licence des fichiers fournis.

GitHub Spec Kit 1.2.1 est initialisé pour Codex. Le dépôt versionne ses skills
dans `.agents/skills/` et ses modèles et scripts dans `.specify/`.
La constitution générée reste un modèle non ratifié.

Les skills complémentaires et la configuration Context7 sont propres à la
machine auditée ; ils ne sont pas installés automatiquement lors d'un clone.
Leur configuration est décrite dans l'audit.
