# Computer vision — understand, choose, diagnose

**60 reference notes and 282 flashcards**, spanning 14 of 14 topics. Agent-authored content; actual device import, recall and personal mastery remain unvalidated.

This curriculum targets an engineer already comfortable with ML/DL. Reference notes explain concepts; flashcards train recall with explicit grading criteria. Coverage of a topic does not imply in-depth coverage of all its variants.

## Getting started

1. Read the [conventions](01-Parcours/Pre-requis.md).
2. Follow the [inventory](01-Parcours/Inventaire.md) or a [career track](01-Parcours/Poles-metiers.md).
3. Attempt each question before reading its expected answer, then explain it in your own words.
4. Prepare Android reviews with the [AnkiDroid guide](01-Parcours/Guide-Anki.md).
5. Record recall and import results in the [progress log](01-Parcours/Suivi-pilote.md).

[Ordered senior curriculum](01-Parcours/Parcours-senior.md): prerequisites, stages and progression criteria.
