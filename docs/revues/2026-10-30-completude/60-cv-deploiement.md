## Corrections applied

reference note: [CV-DEPLOIEMENT](../../../vault/140-ingenierie-systemes/references/143-edge-reproductibilite.md); [flashcards](../../../vault/140-ingenierie-systemes/143-edge-reproductibilite.md). reference note modified before the flashcards.

- **CV-DEPLOIEMENT-001 –  Terminal and additional cost**: in the same sequential model, even an infinite acceleration of the fraction $f=0,1$ limits the global factor to $1/(1-f)=1/0,9\simeq1,111$. If the optimization adds a standardized cost $c$, the time becomes $(1-f)+f/s+c$; for $s=2$, all $c\ge0,05$ cancels the gain of this example. These calculations guide the choice of work to be optimized. They do not predict a competing queue: near saturation, a small reduction in service can greatly change the wait. Then measuring sustained regime, time and quality confirms the practical scope of this analytical marker.

- **CV-DEPLOIEMENT-002 –  Dimensions and zeros**: Removing entire channels can reduce the dimensions of tensors and the work of dense kernels, if all dependent layers are adapted. Setting isolated weights to zero often retains the same dimensions and the same number of operations performed by a dense kernel. A sparse representation can avoid calculations but add less regular clues and memory access. Compare the actually supported pattern and run trace, not just the number of non-zero parameters. Distillation can help a smaller model regain quality, but it is another learning intervention to be evaluated separately from pruning.

- **CV-DEPLOIEMENT-003 — Manifeste reproductible**: Link a version to weight and configuration footprints, input/output contracts, taxonomy, postprocessing parameters, and execution environment. Keeping a sample entry with the relevant intermediate results helps locate the first divergence between versions. Define numerical tolerance and decision tolerance; they are not equivalent near a threshold. The rollback must restore the compatible set, as returning to old weights alone with new class indices can retain a regression. A back-test on a test line verifies this contract without assuming that it will work properly in production.

- **CV-DEPLOIEMENT-004 — Signatures temporelles**: A frequency drop correlated with a thermal rise supports a hypothesis of power or temperature limitation; continuous memory growth suggests another investigation; stable memory with increasing frame age may signal a queue overload. These correlations guide the trials without establishing a single cause. Replaying the same load over a sufficient period of time and changing one factor at a time makes it possible to compare start and steady speed. Also keep accurate, drops and outputs, because holding the rate by abandoning more images changes the service rendered. Validation is about complete sustainable behavior, not just about the time of the first network pass.
